# abTEM research — moved

The notebooks that used to live here have moved to the documentation repository:

### 👉 [github.com/abTEM/doc/tree/main/articles](https://github.com/abTEM/doc/tree/main/articles)

They are the simulation code behind two 2021 publications:

- [`2021_ORE_abTEM`](https://github.com/abTEM/doc/tree/main/articles/2021_ORE_abTEM) — use
  cases from the *ab*TEM methods article, Open Research Europe **1**:24 (2021),
  doi:[10.12688/openreseurope.13015.1](https://doi.org/10.12688/openreseurope.13015.1).
- [`2021_small_interferometric_4D-STEM`](https://github.com/abTEM/doc/tree/main/articles/2021_small_interferometric_4D-STEM)
  — interferometric 4D-STEM of twisted bilayer graphene, Small **17**:2100388 (2021),
  doi:[10.1002/smll.202100388](https://doi.org/10.1002/smll.202100388).

Both are preserved as published and target the *ab*TEM 1.0.0beta API of 2021, so they do
not run with current *ab*TEM. For maintained examples using the current API, see the
[walkthrough](https://abtem.github.io/doc/user_guide/walkthrough/walkthrough.html) and the
[example gallery](https://abtem.github.io/doc/user_guide/examples/examples.html).
